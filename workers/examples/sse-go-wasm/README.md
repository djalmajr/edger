# sse-go-wasm

Real Go (`wasip1`, stdlib only) guest for the host-held SSE of EdgeR
(EDG-55). The guest authorizes and publishes in short executions; the host
keeps every browser connection, so no execution is held per subscriber.

- `GET /events`: `Authorization: Bearer <token>` against the vault secret
  `SSE_ACCESS_TOKEN`; 200 with `x-edger-sse-subscribe: room.1`, or 401.
- `POST /publish`: same authorization; the JSON body
  `{"events":[{"topic","data","event","id"}]}` becomes 1 to 8
  `x-edger-sse-publish` directives (test control channel). Empty list:
  nothing is published.
- `GET /plain`: an ordinary answer. `GET /slow?ms=N`: holds the execution
  for N ms (capped at 5000) and answers 200 (positive control of the
  `activeRequest` reader). Test-only controls: each `topics=` query
  parameter of `/events` becomes one `x-edger-sse-subscribe` header, and
  the `raw` list of the `/publish` body is appended verbatim as
  `x-edger-sse-publish` values. Every route also answers under a leading
  `/api` in the guest dispatch (the fullstack variant, `apiPrefix: /api`). This
  manifest declares only `/events` and `/publish` as SSE routes, so
  `/api/events` is an ordinary route here; the fullstack variant uses its own
  manifest (generated by the test).

`abi.go` is a byte copy of `../go-wasm-http/abi.go` (it imports
`edger_http_v1.fetch`, hence `allowNet: []` plus `egress.enabled` in the
manifest). That pair GRANTS general HTTPS egress: the guard does not read
`allowNet`, so the guest could reach any HTTPS destination the guard accepts
(default port `[443]`, IP classification, revalidated redirects, guard limits);
this guest never calls the import. `allowNet: []` only means the Deno runtime
gets no direct network. The pair is needed only without the managed database
configured (`planning/edger/docs/wasm-abi.md`, "Import HTTP").

## Build (offline)

```sh
GOOS=wasip1 GOARCH=wasm GOTOOLCHAIN=local GOWORK=off GOPROXY=off \
  go build -trimpath -buildmode=c-shared -ldflags='-s -w' -o index.wasm .
```

`index.wasm` is not committed. The binary proof is
`crates/edger-orchestrator/tests/sse_binary_e2e.rs` (`#[ignore]`, WSL Linux):
`EDGER_GO_WASM_SSE_FIXTURE` names the built module and `EDGER_DENO_BIN` the
Deno used by the Deno variant (`../sse-deno`). The test also requires a
`<module>.provenance` file next to the module (SHA-256 of `abi.go`, `main.go`,
`go.mod` and the module, plus a `build:` line equal to the constant in the test,
which builds with `-o sse-go-wasm.wasm`); nothing in this directory writes it.
The manifest sets a worker `ttl` because a `kind: wasm` worker without one
recompiles its module on every request (`planning/edger/docs/wasm-abi.md`).
Host-side behavior and limits: `planning/edger/docs/sse.md`.
